# Roadmap

1. Implementar uma API com autenticação segura e autorização validada no servidor.
2. Conectar o frontend à API e substituir o armazenamento client-side como fonte de verdade.
3. Implementar persistência e migrações para usuários, chamados, atribuição e histórico de atendimento.
4. Garantir atribuição atômica de chamados e sincronização entre usuários e dispositivos.
5. Adicionar testes automatizados para autenticação, permissões, fluxo de atendimento e interface.
6. Adicionar notificações em tempo real e observabilidade quando a infraestrutura do backend estiver disponível.
